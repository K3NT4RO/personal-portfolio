# Personal Portfolio

A responsive personal portfolio website built with HTML and CSS. It introduces me, lists my skills,
showcases my projects and provides a contact form.

**Live site:** https://YOUR-USERNAME.github.io/personal-portfolio/

## Sections
- **Home:** name, profile picture and short introduction
- **About Me:** education (ordered list) and interests (unordered list)
- **Skills:** table of six technical skills
- **Projects:** three project cards
- **Contact:** email address and contact form

## Technologies
- HTML5 (semantic elements: header, nav, main, section, article, footer)
- CSS3 (external stylesheet, Flexbox, Grid, hover effects, media queries)
- Git and GitHub Pages

## Project structure
```
personal-portfolio/
├── index.html
├── style.css
├── README.md
└── images/
```

## Run locally
Download or clone the repository and open `index.html` in a web browser.
